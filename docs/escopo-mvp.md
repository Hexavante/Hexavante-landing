# Escopo MVP — Hexavante Landing

Documento de referência do que está dentro e fora do escopo atual.

---

## Dentro do escopo

Vitrine e catálogo público completo, detalhes como prévia, páginas `/competir`, `/plataforma` e `/sobre`, certificados para logados, header com mega-menu, rodapé social, música de fundo e animações.

## Fora do escopo (futuro)

Login/cadastro próprios, matrícula, prova, compra, blog/CMS, i18n além de pt-BR e testes E2E automatizados.

## Critérios de aceite por entrega

`build` + `typecheck` verdes, páginas com loading/empty states, nenhuma chamada fora da API pública, `curl` 200 nas rotas tocadas.
