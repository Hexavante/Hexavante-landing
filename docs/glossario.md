# Glossário — Hexavante Landing

Documento de referência dos termos usados no código e nas páginas.

---

| Termo | Significado |
|-------|-------------|
| Vitrine | Home (`/`) com prévias do catálogo e CTAs |
| Catálogo | Listas completas com filtros via query string |
| Prévia pública | Detalhe sem ação real + CTA para o app |
| `APP_URL` | `https://app.hexavante.com.br` — destino de todos os CTAs |
| `API_URL` | Base da API no server-side (pode ser interna no Docker) |
| Sessão só-leitura | Cookie compartilhado encaminhado à API; nunca criada aqui |
| Revalidação | 60s nos fetchers públicos (`next: { revalidate: 60 }`) |
| Mega-menu | Navegação Estudar/Competir/Plataforma com painéis e âncoras |
